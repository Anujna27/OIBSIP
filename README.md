# Calculator

A fully functional browser-based calculator built using HTML5, CSS3, and Vanilla JavaScript.

## 📌 Project Overview

This project is a simple and user-friendly calculator developed as part of the Oasis Infobyte Web Development & Designing internship.

The calculator performs basic arithmetic operations and includes features such as decimal calculations, operator chaining, deletion, clearing, and division-by-zero error handling.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Numbers from 0–9
- Decimal number support
- Equals button for calculating results
- Clear button to reset the calculator
- Delete button to remove the last entered character
- Operator chaining for sequential calculations
- Division-by-zero error handling
- Responsive design
- CSS Grid-based button layout
- JavaScript event listeners instead of inline `onclick` attributes
- Built without using `eval()`

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
