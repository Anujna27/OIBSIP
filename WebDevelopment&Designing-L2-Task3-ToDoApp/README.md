# My Tasks — To-Do Web App

A responsive and interactive To-Do web application built as part of the **Oasis Infobyte Web Development & Designing Internship**.

## Features

- Add new tasks
- View pending and completed tasks separately
- Mark tasks as complete or pending
- Edit tasks
- Delete tasks
- Pending and completed task counters
- Task creation timestamps
- Local storage for data persistence
- Responsive design
- Empty-state messages

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
