# M. S. Subbulakshmi Tribute Page

A responsive tribute webpage dedicated to **M. S. Subbulakshmi**, one of India's most celebrated Carnatic classical vocalists.

##  Features

- Hero section with name and tagline
- Biography and life story
- Timeline of major milestones
- Achievements and legacy
- Notable quote
- Responsive design
- Elegant classical-inspired visual theme

##  Tech Stack

- HTML5
- CSS3
- Google Fonts
